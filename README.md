# 📐 Интерактивный тренажёр по математике · Аничков лицей · Поступление в 8 класс

Интерактивный сайт-тренажёр для учеников 6–7 классов, готовящихся к **вступительным испытаниям в 8 класс Аничкова лицея (СПб)**. Программа охватывает алгебру и геометрию по пособию **Б.М. Михлина «Поступающим в физико-математический лицей»**, УМК Макарычева (алгебра 7–8), Атанасяна (геометрия 7–8) и разбор вступительных работ лицея прошлых лет.

Включает **16 содержательных модулей**, **32 урока** (64 варианта: классные и домашние работы), **326 задач** и **360 интерактивных полей ввода** с мгновенной проверкой, а также теоретические памятки к каждому уроку.

🌐 **Готовый сайт проекта:** [https://baikovaalina.github.io/anichkov-liceum-trenazhor/](https://baikovaalina.github.io/anichkov-liceum-trenazhor/)

## 🚀 Особенности проекта

- **Красивая математическая типографика дробей:** обыкновенные и смешанные дроби отображаются с **горизонтальной чертой деления**.
- **Безопасность (GitHub Secrets):** токен бота и Chat ID учителя не хранятся в открытом виде в репозитории. В `main` лежат только плейсхолдеры `__TELEGRAM_BOT_TOKEN__` и `__TELEGRAM_CHAT_ID__`, а реальные значения внедряются автоматически при сборке GitHub Actions из зашифрованных секретов:
  - `TELEGRAM_BOT_TOKEN`
  - `TELEGRAM_CHAT_ID`
- **100% бесплатно и без бэкенда:** GitHub Pages (чистый HTML5, CSS3, ES6 JavaScript).
- **Стилизация под тетрадь в клетку:** аутентичный дизайн с полями, стикерами, удобным шрифтом и крупными кнопками; полная адаптивность под мобильные.
- **Интеллектуальная проверка ответов:**
  - Поддержка обыкновенных дробей (`3/4`), десятичных дробей (`1,5` и `1.5`), отрицательных чисел (`-12`), списков чисел без учёта порядка (`1, 2, 3`), координат (`(3; -2)`), текстовых да/нет.
  - Мгновенная цветовая обратная связь: зелёный при верном ответе, красный с анимацией при ошибке.
- **Автоматическое оценивание:** первичные баллы, процент и школьная оценка (2–5) по шкале ФГОС.
- **Статистика тренировок:** счётчики верных/неверных ответов по каждой работе и по всей сессии, хранение в `localStorage`, кнопка сброса.
- **Интеграция с Telegram Bot API:**
  - Результаты ученика мгновенно приходят учителю в Telegram.
  - Сообщение содержит: ФИО ученика, работу и тему, время решения, баллы, оценку и список ошибок.
- **Резервный вариант:** скачивание подробного отчёта в текстовом файле (`.txt`).

## 🤖 Настройка Telegram и секретов

### 1. Получение Bot Token (для своего экземпляра)
1. Откройте в Telegram **@BotFather** → команда `/newbot`.
2. Придумайте имя и username бота (например, `anichkov8_my_bot`).
3. Скопируйте токен вида `123456:AAE...`.

### 2. Узнать Chat ID
1. Напишите своему боту `/start` (обязательно! Бот не может писать первым).
2. Напишите боту **@userinfobot** — он пришлёт ваш числовой ID.

### 3. Секреты в GitHub
Откройте **Settings ➔ Secrets and variables ➔ Actions ➔ New repository secret** и добавьте:
- `TELEGRAM_BOT_TOKEN` — токен от BotFather;
- `TELEGRAM_CHAT_ID` — ваш Chat ID.

При каждом push в `main` GitHub Actions подставит секреты в `config.js` и опубликует сайт.

### 4. Переопределение в браузере
На сайте нажмите **«⚙️ Настройки Telegram»**, введите Chat ID и нажмите «Проверить связь 🔔» — значение сохранится в localStorage и будет иметь приоритет.

## ✏️ Как обновлять банк задач

Все задания — в файле `tasks.js` в формате:

```js
Q("1", "Заголовок слайда", "— подзаголовок", "Урок 5 · Раздел",
  ["Подсказка к решению"],
  [
    T("а) Текст задания", ["2³ · 2⁵ : 2⁶ =", {_input: 0}], [A("4", "", "1а")]),
  ])
```

- `A(ответ, тип, группа, вес)`: тип `""` — обычный ввод, `"list"` — список без учёта порядка, `"coords"` — координаты;
- несколько приемлемых ответов разделяются `|`: `A("1/2|0,5|0.5")`;
- поля с одинаковой группой оцениваются как одно задание (веса делите между ними, например 0.5 + 0.5);
- дроби в тексте вида `3/4` автоматически отрисовываются с горизонтальной чертой.

После редактирования сделайте commit и push — сайт пересоберётся автоматически.

## ⚠️ Важно: безопасность токенов

- Никогда не коммитьте реальные токены в репозиторий — только плейсхолдеры.
- Если токен попал в открытый доступ (например, был отправлен в чат), **перевыпустите его**:
  1. **@BotFather** → `/mybots` → выбрать бота → **API Token** → **Revoke current token**;
  2. обновите секрет `TELEGRAM_BOT_TOKEN` в настройках репозитория;
  3. сделайте любой push (или запустите workflow вручную), чтобы сайт пересобрался.
- Токен, попавший в опубликованный `config.js` на GitHub Pages, виден всем посетителям сайта — это неизбежная особенность схемы «клиент + Bot API без бэкенда». Она безопасна лишь настолько, насколько вы доверяете аудитории сайта: владельцу токена доступно управление ботом. Храните ссылку в кругу учеников и своевременно отзывайте скомпрометированные токены.
