# 📐 Тренажёр «Поступление в 8 класс Аничкова лицея» · Алгебра + Геометрия

Интерактивный сайт-тренажёр для подготовки к вступительному экзамену по математике в **8 класс Аничкова лицея** (Санкт-Петербург). Задачи составлены по **архиву вступительных работ лицея 2006–2026 гг.** ([spbal.ru](https://spbal.ru/node/11)) и пособию **Л. С. Михлина** «Пособие для поступающих в 8–10 классы ФМШ».

В тренажёре **16 модулей** и **33 урока**. В каждом уроке есть классная работа К-n и домашняя Д-n, всего 66 работ. В них **206 заданий**, **410 задач с ответами** и **447 полей ввода**. Каждый урок снабжён теоретической памяткой и примером решения. Урок 33 — пробный вариант из 7 заданий в формате экзамена.

Дизайн, логика проверки, статистика и отправка в Telegram сделаны по образцу [math6-trenazhor](https://github.com/BaikovaAlina/math6-trenazhor).

## 🚀 Возможности

- **Тетрадь в клетку.** Шрифт, цвета, стикеры и кнопки взяты из эталона. Вёрстка адаптирована под телефоны (от 320 px).
- **Мгновенная проверка.** Верный ответ подсвечивается зелёным, ошибка — красным с анимацией. При ошибке показывается пояснение, а после второй неверной попытки — правильный ответ.
- **Умная нормализация ответа:**
  - пробелы, регистр, запятая вместо точки (`1,5` = `1.5`);
  - дроби (`3/4` = `0.75`) и смешанные числа (`2 1/3`);
  - допуск ±0,01 для приближённых ответов;
  - списки без учёта порядка (`-2; 3`);
  - координаты (`(3; -2)`).
- **Форматы заданий:**
  - ввод числа или выражения;
  - выбор варианта;
  - перетаскивание точки на клетчатой координатной плоскости (геометрия, графики);
  - список корней;
  - текстовый ответ.
- **Баллы и оценка** считаются по группам заданий и весам, как в эталоне. Шкала: 85% и выше — «5», от 68% — «4», от 50% — «3».
- **Статистика в `localStorage`:**
  - по текущей сессии (верно / ошибки / точность);
  - по каждому уроку (последний результат классной и домашней работы);
  - кнопки «Начать новую сессию» и «Сбросить всё».
- **Telegram.** Кнопка «Отправить в Telegram ✈️» есть в тренажёре и на странице урока. Учитель получает: ученика, урок, тему, результат X/Y, время mm:ss, оценку, дату и список ошибок.
- **Резервный вариант:** отчёт можно скачать файлом `.txt`.
- **Без бэкенда и бесплатно:** чистый HTML/CSS/JS, хостинг на GitHub Pages.

## 🤖 Настройка Telegram-бота

1. **Создайте бота.**
   - Откройте [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
   - Задайте имя и username (должен оканчиваться на `bot`).
   - Скопируйте токен вида `1234567890:AA...`.
2. **Узнайте Chat ID.**
   - Напишите [@userinfobot](https://t.me/userinfobot) и скопируйте поле `Id` (число).
   - Для группы: добавьте бота в группу. ID группы начинается с `-100…`.
3. **Нажмите `/start` у своего бота.** Без этого бот не сможет написать вам первым.
4. Если вы сменили бота, укажите его username в `js/config.js` → `botUsername`.

## 🔐 GitHub Secrets и публикация

1. Откройте **Settings → Secrets and variables → Actions → New repository secret** и создайте два секрета:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather;
   - `TELEGRAM_CHAT_ID` — ваш Chat ID.
2. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
3. Сделайте любой push в `main` или нажмите **Actions → Deploy to GitHub Pages → Run workflow**.
4. Что делает workflow:
   - собирает `js/tasks.js` из `data/*.json` и проверяет банк;
   - подставляет секреты в `js/config.js` через `sed`;
   - публикует сайт.

> ⚠️ В репозитории хранятся **только плейсхолдеры**. Никогда не коммитьте настоящий токен.
>
> Обратите внимание: при клиентской схеме (как в эталоне) токен попадает в опубликованный `js/config.js`. Кто откроет исходный код сайта, сможет отправлять сообщения от имени бота. Поэтому используйте отдельного бота только для этой задачи. Если нужна полная защита, вынесите отправку в бесплатный Cloudflare Worker: тогда токен хранится в переменных Worker, а сайт делает `fetch` на URL Worker.

Учитель также может переопределить Chat ID прямо на сайте. Для этого нажмите «⚙️ Настройки Telegram», затем «Проверить связь 🔔». Значение сохранится в `localStorage` браузера.

## 🔄 Ротация (смена) токенов

**Токен бота:**
1. Отправьте [@BotFather](https://t.me/BotFather) команду `/revoke`, выберите бота и получите новый токен. Старый сразу перестанет работать.
2. Обновите секрет: **Settings → Secrets → Actions → `TELEGRAM_BOT_TOKEN` → Update**.
3. Перезапустите деплой: **Actions → Deploy to GitHub Pages → Run workflow**.

**GitHub Personal Access Token**, если он использовался для автоматизации:
1. Откройте **GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens**.
2. Выберите токен и нажмите **Delete** (или **Regenerate**).
3. Если новый токен нужен, выдайте ему минимальные права и только на этот репозиторий:
   - Contents: RW;
   - Pages: RW;
   - Workflows: RW;
   - Secrets: RW;
   - Administration: RW — только для создания репозитория.

## ✍️ Как обновлять банк задач

**Вариант А — правка JSON.** Отредактируйте `data/tasks.json` и `data/lessons.json`, затем сделайте push. Workflow сам пересоберёт `js/tasks.js`, а при ошибке в банке сборка упадёт с пояснением. Чтобы проверить локально, выполните `python3 tools/build_tasks.py`.

Формат одной задачи:

```json
{ "label": "а) Решите уравнение", "parts": ["x = ", {"_input": 0}],
  "inputs": [{ "a": "3/4|0.75", "type": "", "g": "1а", "w": 1 }],
  "e": "Перенесите слагаемые с x влево…" }
```

- `a` — правильный ответ. Альтернативы разделяются через `|`.
- `type` — тип поля:
  - `""` — число или выражение;
  - `list` — список через `;`;
  - `coords` — координаты;
  - `choice` — выбор, варианты задаются в `options`;
  - `point` — точка на сетке, сетка задаётся в `grid`;
  - `text` — текстовый ответ.
- `g` / `w` — группа и вес для баллов.
- `e` — пояснение, которое показывается при ошибке.
- `fig` — статичный чертёж на клетчатой бумаге.

**Вариант Б — Python-DSL (рекомендуется для больших правок).** Добавьте задачи в `tools/author/c_*.py` и выполните:

```bash
cd tools/author && python3 build.py ../.. && cd ../.. && python3 tools/build_tasks.py
```

`build.py` вычисляет выражения в `N(ответ, "выражение")`. Он проверяет, что ответ совпадает с вычислением, что ответ есть среди вариантов и что точка лежит на сетке.

## 🧪 Локальный запуск

Откройте `index.html` двойным щелчком: сайт работает и с диска (`file://`). Другой способ — выполнить `python3 -m http.server 8000` и открыть http://localhost:8000.
